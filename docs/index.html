시연 영상

실제 프로그램을 Docker로 띄우고 조회 → 입고 → 출고 → 재고 부족 안내 → 품목 추가 → 이력 확인 순서로 조작한 화면입니다. 소리는 없고, 아래쪽 자막이 각 단계를 설명합니다.

이 페이지는 설명용입니다. 프로그램은 서버(Python)와 엑셀 파일이 필요해 여기서 직접 실행되지는 않습니다. 직접 써 보려면 소스코드를 받아 docker compose up -d 를 실행한 뒤 http://localhost:8000 에 접속합니다.

사용 가이드

마우스, 키보드, USB 같은 소모품의 재고를 확인하고 입고·출고를 기록하는 프로그램입니다. 내용은 엑셀 파일(data/소모품_재고.xlsx)에 그대로 저장됩니다. 아래 화면은 실제 프로그램을 이 순서대로 조작하면서 캡처한 것이며, 빨간 번호는 설명의 번호와 같습니다.

  1. 접속
  2. 조회
  3. 검색
  4. 입고
  5. 출고
  6. 재고 부족
  7. 품목 추가
  8. 이력
  9. 엑셀 확인

1접속하기

브라우저 주소창에 http://localhost:8000 을 입력합니다. 화면은 네 부분으로 되어 있습니다.

  1. 재고 현황 품목별 현재 재고
  2. 입고 / 출고 수량을 넣고 버튼을 누르는 칸
  3. 품목 추가 새 소모품 등록
  4. 최근 입출고 이력 처리한 기록

프로그램은 프로젝트 폴더에서 docker compose up -d 를 한 번 실행하면 켜지고, docker compose down 으로 끕니다.

2재고 조회하기

  1. 현재 재고 열에서 품목별 수량을 확인합니다.
  2. 오른쪽 위에 전체 품목 수와 총 재고가 표시됩니다.

재고가 0개인 품목은 빨간색으로 표시됩니다. 다른 사람이 처리한 내용은 새로고침(F5)하면 보입니다.

3품목 검색하기

  1. 검색창에 품목 이름의 일부를 입력하고 [검색]을 누릅니다. 예: usb

영문 대소문자는 구분하지 않습니다. 전체 목록으로 돌아가려면 검색창을 비우고 [검색]을 누릅니다.

4입고 처리하기

누르기 전

  1. 입고할 품목 줄의 수량 칸에 숫자를 입력합니다. 예: 무선마우스 10
  2. [입고]를 누릅니다.

누른 뒤

  1. 초록색 완료 알림이 뜹니다.
  2. 재고가 30개에서 40개로 바뀝니다. 이때 엑셀 파일에도 저장됩니다.

실수로 처리되지 않도록 Enter 키로는 처리되지 않습니다. [입고] 또는 [출고] 버튼을 눌러야 합니다.

5출고 처리하기

입고와 같은 방법으로 수량을 입력하고, 이번에는 [출고]를 누릅니다. 예: USB 메모리 5

  1. 완료 알림에 처리 내용이 표시됩니다.
  2. 재고가 50개에서 45개로 줄어듭니다.

6재고보다 많이 출고하려 할 때

재고가 20개인 키보드를 25개 출고하려 한 경우입니다.

  1. 빨간색 안내가 뜨고 처리되지 않습니다.
  2. 재고는 20개 그대로입니다.

수량은 1 이상의 정수만 처리됩니다. 빈칸, 0, 음수, 소수는 버튼을 눌러도 처리되지 않습니다.

7새 품목 추가하기

누르기 전

  1. '품목 추가' 칸에 새 품목 이름을 입력합니다. 예: HDMI 케이블
  2. [추가]를 누릅니다.

누른 뒤

  1. 등록 알림이 뜹니다.
  2. 새 품목이 재고 0개로 목록 맨 아래에 생깁니다. 수량은 4번처럼 입고로 넣습니다.

이미 있는 이름으로는 등록되지 않습니다.

8입출고 이력 확인하기

화면 아래에 최근 10건이 최신순으로 표시됩니다.

  1. 구분 입고, 출고, 등록 중 무엇인지
  2. 재고 변화 처리 전 → 처리 후 재고

잘못 처리했다면 반대로 한 번 더 처리합니다. 예: 잘못 입고한 10개는 10개 출고. 바로잡은 과정까지 이력에 남습니다.

9엑셀 파일로 확인하기

모든 내용은 data 폴더의 소모품_재고.xlsx 에 저장됩니다. Excel로 열면 시트가 두 개 있습니다. 오른쪽은 위 1~8번을 마친 뒤 파일에 실제로 저장된 내용입니다.

'재고' 시트의 수량은 Excel에서 직접 고쳐도 됩니다. 저장한 뒤 화면을 새로고침하면 반영됩니다.

Excel에서 파일을 열어 둔 동안에는 조회만 됩니다. 입고·출고를 누르면 저장하지 못했다는 안내가 뜨니, Excel을 닫고 다시 누릅니다.

문제가 생겼을 때

화면이 열리지 않는다프로그램이 꺼져 있습니다. docker compose up -d 로 켭니다.
'엑셀 파일에 저장하지 못했습니다' 안내가 뜬다Excel에서 소모품_재고.xlsx 를 닫고 다시 누릅니다.
수량을 넣고 Enter를 눌러도 반응이 없다정상입니다. [입고] 또는 [출고] 버튼을 누릅니다.
'재고가 정수가 아닙니다' 안내가 뜨고 목록이 비었다Excel에서 안내에 나온 품목의 재고 칸을 숫자로 고칩니다.
예시 데이터로 처음부터 다시 시작하고 싶다data/소모품_재고.xlsx 삭제 후 docker compose restart web
