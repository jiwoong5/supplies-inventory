시연 영상

실제 프로그램을 Docker로 띄우고 조회 → 입고 → 출고 → 재고 부족 안내 → 품목 추가 → 이력 확인 순서로 조작한 화면입니다. 소리는 없고, 아래쪽 자막이 각 단계를 설명합니다.

이 페이지는 설명용입니다. 프로그램은 서버(Python)와 엑셀 파일이 필요해 여기서 직접 실행되지는 않습니다. 직접 써 보려면 소스코드를 받아 docker compose up -d 를 실행한 뒤 http://localhost:8000 에 접속합니다.
