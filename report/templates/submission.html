1프로그램 개요

회사에서 쓰던 엑셀 파일을 그대로 데이터 원본으로 두고, 조회와 입·출고는 웹 화면에서 처리하는 프로그램입니다. 엑셀을 직접 고칠 때 생기는 실수(잘못된 수량 입력, 재고보다 많은 출고, 변경 기록 누락)를 프로그램이 막도록 했습니다.

재고 조회 (필수)품목별 현재 재고를 표로 표시 · 품목 검색 · 품목 수와 총 재고 요약 · 재고 0개인 품목은 빨간색
재고 변경 (필수)품목 줄에 수량을 넣고 [입고] 또는 [출고]를 누르면 재고가 바뀌고 엑셀 파일에 즉시 저장
오류 방지재고보다 많은 출고와 0·음수·문자 수량은 거부하고 이유를 안내 · 저장에 실패해도 원본 엑셀은 보존
이력 기록모든 입·출고를 엑셀 '입출고이력' 시트에 일시, 수량, 변경 전후 재고와 함께 자동 기록
구조 · 실행재고 로직(inventory.py)과 화면(app.py)을 분리해 로직만 따로 테스트 · 실행은 docker compose up -d 한 줄
